# llm-gateway — agent instructions

Work mode comes first. `/study` for reasoning-critical work (the list is
`.claude/rules/project.md` §6); `/produce` for mechanical work; `/capture`
to close a meaningful session. Skills support the workflow; the rules in
`.claude/rules/` override any skill. If a skill pushes implementation before
Pedro has reasoned through a critical component, stop and return to
`/study`; if it pushes broad refactors or unrelated cleanup, keep the task
scoped.

Grilling (`grill-me`, `grill-with-docs`) belongs to `/study` while the plan
is still vague: one question at a time, on assumptions, invariants, edge
cases, failure modes, testability and operational risk — never turned into
implementation.

Long-term memory: ai-memory (MCP) captures prompts and tool calls by hook
and its tools describe themselves. Write a wiki page only when Pedro asks to
remember something permanently; a handoff is for the next session, never a
permanent note.
